# قائمةُ أوامر هايسفيلد — «فصول»

فيلمُ البطل: **من الورق إلى الجوال**. خمسُ لقطاتٍ مفتاحيّةٍ متطابقةِ الحدود،
ثمّ أربعةُ مقاطعَ بينها، ثمّ تُستخرج إطاراتُها ليُسحَب المشهد بالتمرير في الهيرو.
الأقسامُ السبعةُ أسفلَه تبقى كما هي — لقطاتٌ حقيقيّةٌ من التطبيق.

---

## قراران قبل أيِّ توليد

### ١ · لا نصَّ في أيِّ لقطة
النماذجُ تكتب عربيّةً مشوَّهة — حروفٌ مقطَّعةٌ ومقلوبة. فكلُّ ورقةٍ في الفيلم
تُرى **بزاويةٍ حادّةٍ وعمقٍ ضحل**، فلا يُقرأ منها شيءٌ أصلاً. وفي كلِّ موجَّهٍ:
`no legible text, no lettering, no logos, no watermark`.

### ٢ · شاشةُ الجوال تبقى مطفأة
لو ولّدنا واجهةً على الشاشة لكانت **واجهةً مختلَقة** — وهذا ينقض وعدَ الصفحة
نفسِها: «كلُّ لقطةٍ هنا من التطبيق نفسِه». فالجوالُ في الفيلم شاشتُه سوداءُ
لامعةٌ بانعكاسٍ فيروزيٍّ خافت، والتطبيقُ الحقيقيُّ يظهر في الأقسام السبعة تحته.
الفيلمُ مزاجٌ لا برهان.

### ٣ · بلا أشخاص
لا وجوهَ ولا أيدي. أشياءُ فقط — مكتبٌ وأوراقٌ وضوء. يُجنِّبنا هذا وادي الغرابة
ومسألةَ الاحتشام معاً، وهو أنظفُ بصريّاً لصفحةٍ بهذا السواد.

| # | الملف | المشهد |
|---|-------|--------|
| **K1** | `assets/film-src/k1.jpg` | مكتبُ خشبٍ داكنٍ في عتمة. سجلّاتٌ ورقيّةٌ مكدّسةٌ وأوراقٌ متناثرةٌ وقلمٌ أحمر. الضوءُ الفيروزيُّ يمسح الحافّةَ العليا فقط. ساكنٌ، ثقيل. |
| **K2** | `assets/film-src/k2.jpg` | الأوراقُ نفسُها بدأت **ترتفع** — حوافُّها تنفصل عن السطح، ظلالُها تطول. الترتيبُ ذاتُه، الزاويةُ ذاتُها. |
| **K3** | `assets/film-src/k3.jpg` | الأوراقُ في الهواء تتفتّت إلى **جُسيماتِ ضوءٍ فيروزيّة** — نصفُها ورقٌ ونصفُها ضوء. المكتبُ يخفت. |
| **K4** | `assets/film-src/k4.jpg` | الجُسيماتُ تتجمّع وتتكثّف في **مستطيلٍ واحد**: جوالٌ أسود، شاشتُه **مطفأةٌ لامعة** بانعكاسٍ فيروزيٍّ واحد. لا واجهة. |
| **K5** | `assets/film-src/k5.jpg` | تراجُعٌ للخلف: الجوالُ وحدَه على سطحٍ داكن، والفراغُ حولَه أسودُ خالص. هالةٌ فيروزيّةٌ خافتةٌ خلفَه. |

```bash
# ‏تُرفع المرجعيّةُ مرّةً واحدةً ويُعاد استعمالُ الـid
higgsfield upload create assets/brand/logo-mark.png --json   # ← إن احتجنا الهويّة

higgsfield generate cost nano_banana_2 --prompt "<K1>" --aspect_ratio 16:9 --resolution 2k
higgsfield generate create nano_banana_2 --prompt "<K1>" \
  --aspect_ratio 16:9 --resolution 2k --wait --wait-timeout 25m --json > out-k1.json
```

**كلُّ لقطةٍ تُرى بالعين قبل الانتقال للتي بعدها.** فحوافُّها إن اختلفت انكسر التطابق.

## ب · المقاطع (seedance_2_0 · 16:9 · 1080p · ٥ث)

| # | من → إلى | الحركة |
|---|----------|--------|
| **V1** | K1 → K2 | الأوراقُ تبدأ الارتفاع. كاميرا ثابتة، بطيئة، بلا قطع. |
| **V2** | K2 → K3 | التفتّتُ إلى ضوء. |
| **V3** | K3 → K4 | تجمُّعُ الضوء في الجوال. |
| **V4** | K4 → K5 | تراجُعُ الكاميرا إلى الفراغ. |

```bash
higgsfield generate create seedance_2_0 \
  --start-image <k1_id> --end-image <k2_id> \
  --prompt "locked camera, slow motion, no cuts, no flicker, papers begin to lift" \
  --aspect_ratio 16:9 --resolution 1080p --duration 5 \
  --bitrate_mode high --generate_audio false \
  --wait --wait-timeout 25m --json > out-v1.json
```

`seedance` هو المتقلّب — ٥٠٢ وفشلُ جلبِ المدخلات شائعان. **كلُّ نداءٍ في حلقةِ
إعادةٍ ثلاثيّة**، والمخرَجُ يُتحقّق من وجوده وحجمه لأنّ رمزَ الخروج قد يكون صفراً والملفُّ فارغ.

## ج · الاستخراجُ إلى إطارات

بـOpenCV (لا ffmpeg)، ٢٤ إطاراً من كلِّ مقطعٍ مع إسقاطِ إطارِ الحدِّ المكرَّر
في ٢..٤ ← **٩٣ إطاراً**، عرض ١٢٨٠، q80. ثمّ يُسحَب الهيرو بالتمرير كما كان
العرضُ يُسحَب قبل أن نفكّكه — لكنّه هنا **مشهدٌ سينمائيٌّ لا شاشاتُ تطبيق**.

---

## د · استخراجُ الـresult_url (بلا jq — غيرُ مثبَّتة)

الـJSON يذكر روابطَ **المدخلات** أيضاً، فأخذُ «أوّل رابط» يعيد المدخَل لا المخرَج:

```bash
URL=$(grep -oE '"result_url":[[:space:]]*"[^"]+"' out.json | grep -oE 'https://[^"]+' | head -1)
for d in 1 2 3; do curl -fsSL "$URL" -o asset.mp4 && [ -s asset.mp4 ] && break; sleep 3; done
```

## هـ · الترتيب

1. `higgsfield auth login` ← **المستخدم** (دخولٌ عبر المتصفّح، لا أعمله عنه)
2. `higgsfield workspace set <id>` ثمّ `higgsfield account status`
3. `generate cost` للخمس + الأربعة ← **تُعرض الكلفةُ عليه قبل الصرف**
4. K1..K5 بالتوازي، ثمّ تُرى بالعين
5. V1..V4 في دفعةٍ ثانية (تعتمد على المفاتيح)
6. الاستخراج، ثمّ الدمجُ في هيرو `index.html`
